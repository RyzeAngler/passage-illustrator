# Project setup and production specifications

Complete this setup when taking on a new work. For an existing project, read and check the current specifications, then fill any gaps relevant to this production. Apply the recorded delivery scope to every stage and checklist below, including caption and cover requirements. Record the applicable decisions in the project directory before generating the first story illustration. Reuse them in later chapters. Update equivalent files when the project already has them.

## Apply the skill's fixed art style

Use **Gongbi Narrative Illustration on a Silk-Textured Ground**, as defined in SKILL.md. Include that complete paragraph in reference studies, story prompts, and cover prompts. Record the skill version and the paths and hashes of the production references. Keep the current work's identity designs, layout, and output settings alongside them.

Produce a reference image using this painting technique, open it, and check it against the fixed description. A character sheet or dedicated cover background can serve as the first style reference. This establishes how the built-in style has been realized in the work. Keep production review and user-review status separate. Select the characters, environments, and props from the passage and preserve their source-based states. Depict changing light, weather, and mood within the same technique.

## Model characters, settings, and props across the work

Read the full production scope and inventory the entities that appear, recur, or carry important events. Establish a shared asset index and the current design for each entity. Cover the present scope first, then extend the same index in subsequent chapters.

| Entity | Shared design | State that can change between scenes |
| --- | --- | --- |
| Characters | Stable identity, aliases, species, facial structure, build, hairstyle, identifying features, and stage-specific versions of clothing and equipment. | Current costume stage, injuries, action, objects held, and entrances and exits. |
| Settings | Entrances, exits, orientation, fixed features, terrain, important buildings, and their relative positions. Draw a plan or orientation sketch where needed. | Viewpoint, light, movable furnishings, positions of figures, and the effects of events in the scene. |
| Props, weapons, and extraordinary objects | Quantity, silhouette, components and joints, material, color, proportions, and identifying features. | Possession, open or closed state, damage, changes of form, grip, and placement. |

For each entry, record a stable ID, identity or type, story stage, version, source evidence, artistic choices, scope of use, written description, paths and hashes of actual reference images, and production-review status. Appearance left unspecified in the source may be designed. Once adopted, that design becomes a continuity requirement for the work. Mark stages that have yet to appear in the source as future stages or pending design.

Prepare reference images for recurring characters that establish recognizable facial features, build, and clothing. Add the views needed for changes of viewpoint. Before first use, establish the construction and handling of key objects and the fixed layout of recurring settings through suitable reference images or structural sketches. When generation and image-viewing tools are available, create and inspect these references. Link written designs and visual references in the index. List any work that remains pending because of limited resources or other constraints, and explain its effect on continuity.

For every image, bind the entity IDs, story stages, and versions in the storyboard and production list. Also record the state at the beginning of the scene, the change depicted, and the state at the end. Expand the necessary visible features in the generation prompt and supply the actual references needed for that request. Use the preceding story illustration to supplement the state of the scene. The shared designs establish stable identity and appearance.

## Plan captions and the cover from the outset

For a standard chapter or series production, the default deliverables are one separate cover and N captioned story illustrations. Each story illustration includes an editorial scene title and a corresponding quotation from the source. Add a location label where useful. Honor explicit requests for unlettered artwork, a single illustration, or a specific stage such as storyboarding. Record that scope in the production specifications.

For an illustrated Chinese classic with no existing layout, use portrait 1080 × 1920 sRGB PNGs. Set the main text vertically in a Kai-style typeface, with columns read from right to left. Use muted cinnabar for editorial titles, an ink tone for the quotation, and a soft paper-colored backing where needed. Reserve space according to the actual text. Select an appropriate layout for other languages and reading contexts. Use a readable font file that contains the required glyphs. Record numerical settings and exceptions in the configuration. Keep image IDs, provenance, and review status in the production records.

Select the quotations and record their source IDs while storyboarding. Plan the editorial titles and text areas at the same time. After accepting the master artwork, use a typesetting tool to render the text into the finished PNG. Retain the master without editorial captions. Check the wording and reading order in the actual finished image.

For a new series, prepare dedicated cover artwork. Use the fixed art-direction paragraph in SKILL.md and the cover prompt to generate it, then open and review the result before establishing the title template. Use the existing cover template: the chapter identifier followed by the original chapter title. For a two-part Chinese chapter title, set the three vertical columns from right to left as chapter identifier, first title line, and second title line. Retain a transparent type layer. Reuse the accepted cover artwork and layout in subsequent installments.

## Check before generating story illustrations

- The fixed style paragraph in SKILL.md is applied to the prompts, and its reviewed production reference is available.
- Characters, settings, and props appearing in the current production have designs, story stages, and current versions. The key references are ready and each image's reference assignments are complete.
- For captioned output, quotations, editorial titles, layout, and clear space are planned for each image. A recorded wordless or stage-specific request defines the applicable work.
- Where the delivery scope includes a cover, its artwork and template have an accepted source or are scheduled for actual production in this task. The cover wording and output paths are explicit.

If only the story masters have been completed, continue with the agreed captions and cover. When technical or resource limitations block progress, identify the outstanding items and the stage actually reached.
