# 依据原文制作插画

以用户指定的底本为剧情和引文依据。通读制作范围，按情节密度和用户要求确定图数，为每幅画选定一个可见瞬间。画风采用下文固定标准，角色、器物和场景沿用本作有效设定。画幅、成品尺寸、阅读方向、画内文字、画外配文与系列封面服从作品规格。

用户要插画时，调用宿主可用的图像生成或编辑工具，逐图打开实际结果核对后交付。用户只要分镜、提示词或审阅时，做到该阶段。缺少生图或看图能力时，标明未执行的环节和可接续使用的材料。

## Skill 固定画风

**绢本工笔设色叙事插画**

采用仿绢本工笔设色的叙事插画风格。以细劲、连贯、富有轻重变化的墨褐线勾勒轮廓，清楚表现人物面貌、衣褶、器物构造和建筑细节。以低饱和的石青、石绿、赭石、米白为主要色彩，少量朱砂点染，通过分层薄染形成温润、哑光的矿物色质感。画面保留浅暖绢底和细密肌理，明暗节制，光照柔和。人物比例自然，形体结构、动作、握持与受力可信。山石草木、建筑和器物以疏密有序的笔线与设色统一表现，远近层次清楚，背景适度淡化，突出人物和关键情节。整体气质古朴、清雅、含蓄，兼具传统绘画的细腻与叙事画面的可读性。

这段是 Skill 自带的统一画法，适用于人物设定、场景、道具、故事图和封面，逐次生图时写入完整提示词。阅读原文用于确定主体、情节和现场关系；时段、天气与情绪在同一画法内表现。用户明确要求改变绘画技法时，先与用户确认再调整。

## 首次制作先建立作品设定

新作品开始时读取[新项目建立与制作规格](references/project-setup.md)。在第一张故事图生成前，执行上文固定画法，建立并保存人物／场景／道具的全局设定，以及本次交付需要的配文和封面规格。

章节、整回或系列图文制作默认交付**一张独立封面＋N 张带情节题签和原文配句的成图**。分镜时选句并安排留白，最终文字须实际排进 PNG。新作缺少封面底画和模板时，本次建立并制作。用户明确要求无字图、单幅插画或只做某个阶段时，按其范围执行并记入规格。

新作品先为本次出场的实体建立全局设定和有效版本，准备并核对首用参考，再逐镜绑定。后续章节在同一索引增补，相关前图提供现场状态参照。

## 制作顺序与采用条件

| 阶段 | 必须完成的工作 | 进入下一步的条件 |
| --- | --- | --- |
| 原文 | 提取正文、稳定段落编号、记录来源 | 篇章范围、次序、字词与底本对应 |
| 全局建模 | 应用固定画法，建立实体设定与参照任务，安排配文版式和封面 | 出场实体有身份与版本，固定画法已应用，交付清单明确 |
| 分镜 | 确定图数、单一瞬间、原文事实、创作补充和逐图验收要点 | 叙事连续，动作、机位与剧情阶段相容 |
| 资产 | 建立或检索有效身份、阶段、器物和场景，逐镜绑定版本与已核对参照 | 关键特征明确，实际使用材料可读取且已核对 |
| 提示词 | 形成完整、细致、无冲突的绘画说明 | 主体、动作、器物和方位有唯一指向，关键关系可画、可见 |
| 底图 | 逐图检查原文、物理与空间、连续性 | 已确认错误全部修正，关键适用项全部通过；关键项看不清时继续复核或修正 |
| 成图 | 按记录的交付范围制作成图；普通章节包含实际配文 PNG、独立封面和文字层，复核全幅与细节 | 内容正确，裁切和文字不破坏关键关系 |
| 交付 | 检查文件与包内内容，更新当前验收结果 | 视觉和技术检查均有效，链接可用，材料能支持继续修改和重新导出 |

生成成功不等于制作验收通过。制作目视复核、技术检查和用户审阅分别记录；不得把工具检查或代理采用写成用户已确认。已有授权范围内的制作和返修可继续执行，不将每张图的复核都变成额外的用户审批。

## 工序与文件位置

先提取并通读原文，再建立全局实体模型、分镜绑定和制作参照，然后生成故事底图、排入配文、合成当章封面，最后复核导出。首张画法参照直接使用上文固定段落。系列独立封面底画可以在全局参照准备阶段并行制作，核准当章标识和标题后完成封面排字。

沿用既有制作目录。全局模型和版本放在 `美术资产库/`，索引为 `美术资产库/资产索引.json`。共享封面底画和模板放在 `账号物料/系列封面/`，各回配置、平面封面和文字层放在本回 `封面/`，故事成图放在本回 `成图/`。完整目录见[工作目录布局](references/materials.md#工作目录布局)。

制作代码文件统一使用英文 ASCII 文件名，采用小写 snake_case，例如 `tools/typeset_chapter.py`、`tools/render_cover.py`。已有中文脚本更名时，一起更新调用入口和文档。

## 各阶段操作

1. 定位用户指定底本和本次制作范围，读取[新项目建立与制作规格](references/project-setup.md)，确定作品根目录及已有原文记录、设定、版式和封面材料的位置。见[材料与文件职责](references/materials.md)。
2. 提取并通读原文，应用固定画法，先建立或核对全局人物、场景和道具设定，准备必要参照，再编排分镜、逐镜绑定实体版本与状态并选定原文配句。见[原文提取与分镜](references/source-and-scenes.md)和[资产与连续性](references/continuity.md)。
3. 按下文的提示词编写标准和[内置模板](references/prompts.md)写出本镜完整绘画说明，写入统一画法段落及所绑定实体的可见特征，本次包含封面时为其准备专用输入，检查后提交；生成候选图。
4. 打开实图，按[生成、校验与返修](references/review-and-revision.md)核对原文、物理与空间、跨图连续性。根据错误所在环节返回分镜、提示词、资产或底图，复核后再采用。
5. 按首次确定的范围完成成图；普通章节实际导出带配文的 PNG、独立封面和文字层，并对照清单查漏，再按[配文、封面、导出与交付](references/delivery.md)检查成品，并按[材料保留与清理](references/materials.md)整理当前工作。需要使用附带的 [PNG 排版导出工具](scripts/export.py)时，读取[导出配置](references/export-format.md)。该工具需要 Python 3.10+ 和 Pillow 10.1+。

## 提示词编写标准

每幅提示词必须是一份可独立理解的完整绘画说明，充分、细致地描写该镜头所需的人物、动作、器物与环境。按画面复杂度展开，在工具输入限制内保证有效信息完整，不以压缩字数为目标，也不靠重复形容词增加篇幅。

### 标准内容与展开要求

按以下顺序组织自然语言段落；复杂主体分别描述，相关动作与结构放在同一段，保证前后指向一致。

| 内容 | 必须写清的视觉信息 |
| --- | --- |
| 画面主题 | 画面类型、地点、时段、主事件与唯一瞬间；用可见状态交代必要前情 |
| 人物形象 | 出场数量、身份、物种、面貌、体型、发毛、服饰层次、冠饰、装备和剧情阶段；区分每位主要人物 |
| 人物动作 | 躯干朝向、肩肘腕和髋膝踝的关系、左右手分工、腿脚位置、动作对象、主动与回应关系 |
| 表情与视线 | 眉眼、口部、头部角度和目光落点；情绪落实为可见变化，旁观者的反应指向具体人或物 |
| 道具结构 | 每件物体的数量、轮廓、构件、连接、材质、颜色、尺寸比例、朝向和当前完整／损坏等状态 |
| 接触与受力 | 手怎样包握或托举、脚与支撑面怎样接触、重心与承重点在哪里；遮挡前后露出的结构怎样连接 |
| 场景空间 | 前中后景、人物站位、相互距离、地形、建筑、出入口、固定构件与环境细节，保持同一空间体系 |
| 镜头构图 | 观察方位与高度、景别、透视、裁切、视觉中心、层次和轮廓间隔；必须清楚呈现的关键部位 |
| 光色与画法 | 光源方向、明暗层次、色彩关系、线条、设色、肌理与材料差异，形成统一环境气氛 |
| 连续性与输出 | 本镜必须延续的特征和允许变化的状态、画幅、画内文字、配文留白与针对本镜的必要排除项 |

不适用的项目可省略，已存在且影响画面的信息必须写全。远景不要求不可见的微小结构；若微小结构决定剧情，应先改变机位或景别。背景描写服从场景和叙事，不为丰富画面擅增人物、装备、事件或地标。

### 表达规则

1. **明确归属**：多人动作逐人写清谁做、对谁做、用哪只手和哪件物体。对可能混淆的主体重复名称，避免含混指代。
2. **统一瞬间**：所有肢体、表情、道具和环境处于同一时刻。未来动作留在分镜的叙事说明中，提示词只写当前可见内容及必要的阶段限制。
3. **统一属性**：同一对象的名称、材质、色彩、构件、数量和状态前后一致，不能用不同泛称暗示不同造型。
4. **统一方位**：区分人物自身左右和画面左右；明确观察者位置，所有朝向、遮挡和透视服从该视点。
5. **具体结构**：写清构件怎样连接、哪个面朝向观察者、哪里被遮挡。不能只写“结构正确”“自然”“合理”或“保持一致”。
6. **明确尺度**：用可见的人体、地面、构件或同景物体说明大小与长度关系，考虑远近、俯仰和透视；不同镜头不直接比较像素长度。
7. **充分可见**：关键动作、接触点和数量需要足够画面空间。不得用云雾、袖口、裁切或配文遮住问题来代替修正。
8. **信息自足**：管理编号、资产版本和文件名留在制作清单；绘画说明中展开必要视觉特征，不以编号或“沿用上图”代替描述。
9. **输入对应**：实际提供图片时，在本次请求中按输入顺序说明各自用途、应保留的特征及本镜重定的内容。没有传入图片时不引用不存在的图号。
10. **参数匹配**：画幅和构图写入说明，工具支持的尺寸、蒙版和其他参数在调用处设置。负面提示、权重等按实际模型能力使用，不混用不同模型的专用语法。
11. **完整整理**：修订采用后重写相关段落，删除被替代的姿态、材质、机位和重复要求，始终维护一份无冲突的完整提示词。

### 故事图与封面的提示词

按本次操作从[内置绘画提示词](references/prompts.md)选用对应模板，把本镜事实、设定和可见关系写成完整正文。完整正文既是发给图像工具的输入，也是逐图保留的有效提示词。局部编辑的单次指令在采用后整合回该图的全文。

- **首次绘画**：完整覆盖本镜主题、人物、动作、空间、器物和画法，不依赖未提供的聊天上下文或项目记忆。
- **跨镜续画**：先明确保持的特征与现场状态，再明确本镜变化；同机位写固定位置和接触关系，换机位重新描述视点下的前后、左右和遮挡。
- **局部编辑**：明确目标图、可见问题、修改范围、改后关系和必须保留的内容；范围包含必要的相连结构。一次编辑指令服务于当前操作，采用后把结果整合进完整提示词，不要求永久保存编辑流水。

- **封面底画**：使用统一画法生成独立封面构图，预留标题空间；打开审阅后按原模板合成回数与原著回目。

### 提交前检查

提交前将提示词读成一幅静止画面，并与原文、分镜和当前设定核对：

- 人物身份、数量、动作对象、器物归属和剧情阶段是否正确，有无无依据的增加或提前出现。
- 每个人的手脚、姿态、表情和视线是否能同时成立，是否存在同一肢体承担相互冲突动作的要求。
- 道具构件、数量、连接、朝向和尺度是否完整，握持、承重及遮挡能否成立。
- 机位、景别、构图和配文留白是否相容，关键结构是否实际可见。
- 连续性要求是否展开成具体特征，当前版本是否仍混有旧状态、含混指代或相互冲突的句子。
- 实际输入、图片顺序和用途是否与请求相符；工具若有扩写或改写功能，不得任其改变原文事实和已确定的视觉关系。

发现问题先改分镜、机位或提示词，再提交生成。提交检查是制作动作，只将有效决定写回对应材料，不另产一份提示词检查报告。
