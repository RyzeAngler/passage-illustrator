# 行为验收用例

在空作品目录运行。将请求和原文交给只获得本 Skill 的 Agent，保留实际输出供核对。目视判据对应当前输出，遇到“看不清”须保留该状态。比较版本时可用同一宿主和原文运行有、无 Skill 两组。

| 用途 | 请求与材料 | 核对输出 |
| --- | --- | --- |
| 写景单图 | 为“潮水刚退。灰色石阶的最低一级上，留着一枚白贝壳。”制作横幅无字插画。 | 打开图看贝壳数量、颜色、相对台阶和水位。人物、招牌和出版装饰不应擅自出现。 |
| 交接及时间跳转 | “进门时，叶禾手里攥着一枚黄铜纽扣。她把它放进空碟子，转身走了。天黑后，阿冬才端走碟子。”做三幅分镜与可单独使用的提示词。 | 逐幅核对持有者、碟子状态和阿冬的出场时刻；同一纽扣、碟子可识别；每次只描写该瞬间。 |
| 修正既有图 | 在第一例底图上排入原句“潮水刚退。”，把底图、配文配置和成图提供给 Agent，要求将画面中央的短句移到上缘。 | 从无字底图重排，仅改变文字位置；核对原文、画面遮挡、最终哈希，制作审阅和用户反馈分开。 |
| 仅审阅 | 给一幅贝壳被水面遮住、阶数无法判定的候选图，对照第一例原文询问能否采用。 | 检查实际局部，指明不可辨的关键关系，提出可执行的机位或构图修改，保留待复核状态。 |
| 触发边界 | 分别请求“按这段原文续画下一幅”和“帮我修订这段散文的标点”。 | 前者进入连续性检查；后者只是文字编辑，无需启动插画流程。 |

例中的横幅、贝壳和用色只属于该项任务。评估阅读的是实际图像、分镜、提示词或修改结果，不能用出现了多少个标题代替判断。
