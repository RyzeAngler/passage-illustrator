# 生成、校验与返修

逐图生成候选，打开实际图像检查。先看无配文的全幅，独立描述看见的主体与动作，再核对原文和预期；随后放大关键局部，最后与相关镜头并排比较。缩略总览、生成说明和输入文件校验均不能代替读图。

## 三类必检内容

| 类别 | 判断依据 | 逐图核对内容 |
| --- | --- | --- |
| 原文符合性 | 对应正文、剧情阶段、已明确的创作补充 | 出场身份、物种、数量、动作、对象、先后、能力、物件归属及现场结果；画面表达是否符合本镜情节 |
| 物理与空间逻辑 | 身体和器物结构、动作、机位与环境 | 肢体连接、左右、握点、承托、重心、落地、穿插、遮挡、轴线、构件连接、尺度及透视是否相互成立 |
| 跨图一致性 | 全局有效设定、前文相关镜头、本段连续镜头 | 面貌体型、服饰阶段、道具材质结构比例、场景固定关系、当前状态；变化是否由剧情、动作或视点解释 |

作品中的形态变化和特殊能力按原文设定判断，不强行套用普通形态；除此之外，仍需交代形体、空间和接触关系。连续性允许合理的姿态、表情、时间和视角变化，不要求不同机位画面逐像素一致。

## 判定与采用

- 分镜先列本镜关键要求。每个适用项目记录“预期要求—实际观察—核对依据—判定”，结论为“通过”“有误”“看不清”；确实不适用的项目说明原因，不能借此略过难点。
- 关键内容看不清时，先放大或检查底图；因景别、遮挡、构图导致无法辨认时调整画面。不得把“没有发现问题”或低置信猜测写成通过。
- 任一已确认错误都须修正，不能将其列为非关键项而跳过。原文、物理与空间、连续性的关键项全部通过且无已知错误，才可采用为正式底图。仍有误或无法判断的关键特征不得作为后续图片的可靠基准。
- 共用资产的首用图、复杂交手、多人递物、数量与形变等高风险内容应增加一次独立复核：重新从图像作判断，不沿用生成者的结论；有条件时由另一审阅者复核。
- 通过后的正式底图保留原始像素，画内文字和器物已处理妥当，尚无画外配文。导出时一次性适配成品尺寸，不反复放大保存。

## 按原因返修

| 问题 | 处理及复查范围 |
| --- | --- |
| 提示词含混、相互冲突或漏写关键关系 | 先统一分镜与完整提示词，再重绘或编辑相关画面 |
| 人脸、手足、冠饰、器物局部有误 | 编辑问题及必要相连区域，复核整个人物或物体、接触位置和全幅关系 |
| 情节、机位、构图或空间整体错误 | 回到分镜调整，不用遮挡或局部补丁维持错误整体 |
| 多图重复同一错误特征 | 核对共同设定和实际输入，修正后复查所有受影响图 |
| 同机位固定关系漂移 | 在有效底图上限定修改范围；确需像素不变的区域用合成方式保留并核对 |
| 画内文字有误 | 逐字修正，再核对载体、透视、材质与位置 |
| 画外配文、字号或位置有误 | 修改排字配置重新导出，不重绘无关画面 |

每次返修后复核当前全幅、改动局部及相关连续镜头。某一区域像素未改只能证明没有改动，不能证明它原本正确。

更新图像、机位或资产后，受影响的旧检查结论失效。未受影响的项目只有在已有有效判定、对应内容未变且关系未受牵连时才可沿用；有疑问就重核。当前验收结果必须覆盖所有适用项目，不能只保留最后修改部位的观察。

## 当前视觉验收记录

作品的目视审阅记录保存每张图及封面的当前结果：图号、底图或成图路径与哈希、审阅者、核对的原文和有效设定／图像版本、逐项观察与判定、未解决项、制作复核状态和用户审阅状态。

底图与成图分别关联各自哈希，相关参照改变后重新核对对应项目。记录只描述当前有效状态，不追加每轮返修经过；无需默认生成局部截图、拼图或单独审阅报告。临时检查图仅在判断确有需要时制作。
