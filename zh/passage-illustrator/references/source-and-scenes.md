# 原文提取与分镜

### 原文

1. 确认指定底本与本次制作范围。粘贴的原文按段落或行定位；EPUB 从目录、章节标题和内页定位，分页文档记录页码与页区。章节次序以实际正文为准。
2. 按正文顺序提取，区分正文、诗词和现代注释；清除脚注链接标记，保留原词、标点和段落顺序。
3. 正文块顺次编号，确立后保持稳定。未辨明的图片字保留字形证据，不凭其他版本补写；配文避开未核实字形。
4. 通读整段或整章，梳理人物出入、动作因果、身份变化、物件获得、地点转换和时间跨度，将影响制作的结论写入分镜总说明。

原文事实与美术设计分别标明。原文规定的身份、物种、数量、归属、先后和字句必须遵循；未规定的外观、镜头、光色和空间细节可作设计，但不得与原文冲突。查后文补足身份或器物信息时注明出处，不能把后续阶段的装备和能力提前画入。

### 分镜字段

| 字段 | 内容要求 |
| --- | --- |
| 图号、标题 | 阅读顺序和简短情节名称 |
| 原文依据 | 段落编号及支持本镜的摘录，覆盖动作、人物和地点，不只摘配文 |
| 叙事作用 | 本图表达的信息，与前后图的因果关系 |
| 定格瞬间 | 当前单一动作，以及此前动作在现场留下的可见结果 |
| 人物与阶段 | 出场人物、当前外貌衣装、已获得和未获得的物件及能力 |
| 场景与机位 | 地点、观察方向、高度、景别、固定构件及空间层次 |
| 动作与构图 | 各人的动作对象、表情、视线、接触位置、遮挡及画面焦点 |
| 连续性 | 延续的身份、物件、位置和状态，以及本镜确有依据的变化 |
| 创作补充 | 原文未规定但画面必须确定的造型、分工和姿势，标明适用范围 |
| 配文 | 当前情节对应的原文、段落编号、题签和地点 |
| 验收要点 | 原文、物理与空间、连续性各项的预期结果及关键可见关系 |

多图先在分镜总说明写明情节起止、图数理由、省略内容和时序边界。写景或诗文以观察视点、意象或景物关系确定本镜主题；原文中的比喻与回忆要辨明叙述层次。

分镜完成后先连续阅读，检查情节是否可理解、前后状态是否接续。复杂动作先确定姿态和机位；关键接触点被遮挡、景别不足以呈现剧情信息时，先调整构图，不能指望配文补足画内错误。
