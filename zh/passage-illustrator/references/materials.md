# 有效材料与文件职责

每项信息只维护一个有效来源。作品说明只写当前制作所需的结论。下列材料是制作职责，可落在项目已有的文件或记录中。

| 材料 | 保存内容 |
| --- | --- |
| 全局美术设定与资产索引 | 明确画风名称或完整描述、可复用画法段落、已审阅风格参照、输出与配文版式、稳定实体 ID、阶段版本和实际参考文件。保存于作品级位置，跨章节持续更新。 |
| 底本与来源 | 有序的段落或诗行、稳定 ID、类型、原文。记录文件名、版本、章节或页区；文件底本保留 SHA-256。未辨明的图片字保留必要的原页证据。粘贴文本保留原段。 |
| 分镜决定 | 总说明保存本段情节起止、图数理由、省略内容、时序边界和必要规格差异。逐图条目保存原文依据、本镜瞬间、构图、创作补充及验收点。 |
| 绘画说明 | 每幅一份当前完整提示词，文件制作时保存为逐图 TXT。局部编辑采用后整合回全文。 |
| 制作与绑定 | 每个图号对应提示词、人物和资产的身份／阶段／版本、实际文件与用途、有效底图及哈希。模型和参数仅记录工具实际提供的内容。 |
| 配文与位置 | 配文、摘句出处、题签、坐标、字体、版式、裁切重心与封面配置。修改应反映在实际成图中。 |
| 导出结果 | 成图、封面与透明文字层、图片清单、审阅入口、下载包及实际执行的技术检查。清单由导出操作生成。 |
| 目视结论 | 底图和成图各自关联当前文件哈希，以及核对的原文、参照版本和逐项判定。制作复核与用户审阅状态分别记录。 |

图号只表示固定阅读顺序；底图、成图和提示词用同一图号对应。身份、剧情阶段与设计版本分别管理。资产索引及共享模板以作品根目录为基准，镜头文件和导出结果可相对本次制作目录；在配置中确定基准，Markdown 链接相对所在文档。使用附带导出器时，输入路径均相对作品配置，配置中的 paragraphs 是该次导出的原文输入；已有权威正文时由它生成这些字段。整组阅读版与缩略总览按需生成。

## 产物边界与清理

只保留继续修改、复用、重新导出或验收仍需使用的材料。当前有效状态写回所属文件，不为沟通、调研或返工经过另建记录。

| 类别 | 处理规则 |
| --- | --- |
| 底本、来源、必要原文证据 | 保留，作为剧情和引文依据 |
| 当前脚本、完整提示词、制作清单 | 保留唯一有效内容，不另维护重复汇编和绑定表 |
| 有效资产、正式底图、排字及封面源材料 | 保留；跨篇章仍有引用的版本不能删除 |
| 成图、封面及文字层、清单、HTML、ZIP、当前验收结果 | 保留当前有效交付 |
| 正文／脚本阅读版、整组缩略 JPG | 按需自动生成，唯一数据源改变后同步更新或撤下失效入口 |
| 候选图、临时裁图、放大检查图、拼图、对比页、蒙版和补丁 | 仅在制作确有需要时临时使用；采用合并且无依赖后清除，不要求归档 |
| 未采用提示、失败日志、逐轮编辑指令、沟通经过、旧清单、重复规格报告 | 不列为流程产物，不额外生成或永久保存 |
| 临时脚本、缓存、失效且无人引用的试作版本 | 确认无有效依赖后清除，不搬入另一份历史目录 |

清理前先列出当前材料及跨篇章引用，确认仍参与制作的文件；将采用的内容整理到正式位置，更新任务、配置和链接，验证文件及重新导出能力后，再删除确实失效的临时材料。

正式底图、全局封面背景、有效多视角资产和当前验收依据不是废弃中间产物。必要局部或源文件若仍被当前结果引用，应保留其有效内容，不能只因名称含“候选”“版本”而删除。

清理不改变审阅结论，不扩大到项目外缓存或其他项目。工具减少默认产出时同步调整展示链接，不自动删除既有作品文件；既有材料的整理按其实际依赖单独进行。
