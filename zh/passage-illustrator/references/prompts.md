# 内置绘画提示词

下面模板分别用于首次绘画、跨镜续画、局部编辑和独立封面底画。由执行制图的 Agent 从原文、分镜与有效资产中填写【】内的内容，合并为流畅、自足的绘画说明，再把正文交给图像工具。无人物的镜头省去人物段，未传参考图时省去绑定语句。多人、多件器物或复杂空间按需要展开成若干段。用户只需提供原文或指出项目材料。

## 首次绘画

~~~text
采用 Skill 固定的绢本工笔设色叙事插画画风，【完整插入 SKILL.md 固定画法段落】。沿用本镜绑定的【人物、场景、道具版本的具体可见特征】。

绘制一幅【本次画幅】插画。地点是【地点和可见环境】，时间是【影响画面的时段】。定格在【本镜唯一瞬间】。观看者首先应看见【承担叙事的主体及其可见状态】；【已经发生的事】在现场留下了【此刻仍可见的痕迹】。

【主要人物的名称、身份和当前阶段】位于【相对位置】。【体型、面貌、发毛、衣装层次和本阶段拥有的装备】使其可辨。身体朝向【对象】，头部【角度】，目光落在【具体位置】；【眉眼、嘴部和可见姿态】共同表现此刻的反应。【哪只手或身体哪一部分】在【接触点】对【人或物】做【当前动作】；【脚、支撑面和重心】使这个姿势成立。【其余人物的独立外形、动作对象和回应，与主要人物的距离】。

【关键器物或景物】共【数量】，其【颜色、轮廓、材质、构件和连接方式】可见，与【同景参照物】相比大小为【比例】。在这一刻它【归属、朝向、完整或变化后的状态】，通过【握持、承托、悬挂、落地或与周围景物的关系】处于【位置】。从当前视点能看清【决定情节或意象的细节】。

从【观察者方位与高度】以【景别】看向【主体】。近处【前景及遮挡边界】，中景【人物、器物或主要景物的相对位置】，远处【场景延伸和固定构件】。【焦点和裁切边界】使【必须看清的数量、部位或接触点】完整可辨。

光从【方向】落在【具体表面】，用【线条、设色、明暗和材质的处理】表现【作品画风及氛围】。【画内确有文字时的准确字串、载体与朝向】。【已选原文配句和情节题签所需的留白位置及保留的背景纹理；本次明确为无字图时省去】。
~~~

写景、静物或意象镜头把细节用于景物的形态、空间、光色和时间痕迹。只把原文规定或美术设计确实需要的内容写进本镜。[《潮退以后》导出样例](../examples/tide-line/project.json)用于演示原文定位与导出，其版画图像和原始提示词保留早期样例的制作依据。新绘画面使用上文固定画法。

## 跨镜续画

~~~text
采用绢本工笔设色叙事插画画风，【完整插入 SKILL.md 固定画法段落】。绘制同一作品的下一幅【画幅】插画，本镜定格在【这一次发生的单一动作或状态】。

本次输入的第【序号】张图用于【身份、器物、场景或画法】，取其【已核实的具体视觉特征】。第【序号】张图提供【现场状态或另一项参照】，取其【实际可见且本镜应延续的特征】。

此刻【出场主体的身份及当前外形、衣装】，仍带有【跨镜识别特征】。【同一器物的轮廓、构件、材质、相对尺寸】在这幅里清楚可辨。现场保留【固定构件之间的位置、上一动作留下的痕迹】。本镜发生的变化是【谁移动、谁取得或放下何物、姿势或环境如何改变】，变化后的可见结果为【明确的持有者、接触处和空间位置】。

观察者位于【本镜方位、高度】，采用【景别及裁切】。从这里看，【主体、固定物和出入口的前后关系】；【人物自身哪侧】面向【对象】，【哪一部分遮住何处、何处仍须露出】。视觉中心落在【本镜叙事关系】，以【表情、视线、动作或环境痕迹】表现。沿用【具体线条、用色和材质表现】，按照本镜的【时间及光源方向】处理明暗。【画内字与配文留白要求】。
~~~

同机位写出固定构件与接触点。换机位按本镜所见重述左右、遮挡和投影。把识别特征写进正文，即使没有随调用提供前图，也能凭完整说明生成。参考图只写实传数量及顺序，身份图与现场图各自只负责明确指定的部分。

## 局部编辑

~~~text
编辑本次输入的【目标图序号或可唯一辨认的目标图】。需要修改的是【画面位置、主体及可见问题】。本镜应呈现【与原文和分镜对应的改后状态】。

将【具体错误部位】改为【正确的数量、造型、方向或动作】。【相连的肢体、构件、遮挡边缘或影子】随之调整，使【握持、连接、受力、透视或文字与载体的关系】成立。从原机位应能直接看见【本次修复后可以逐项核对的结果】。修改范围到【包含必要相连结构的边界】为止。

保留【已正确的人物面貌、衣装和姿态】、【器物身份和场景固定位置】、【原图景别、裁切、光向、线条与材质】。修整处与周围的【具体轮廓、纹理、明暗或笔触】自然衔接。【有额外实传参考图时写明其顺序，以及只用于核对的特征】。
~~~

整幅时点、机位或构图错误时，回到分镜后使用首次绘画或续画模板。只改画外配文时，直接改排字配置并重新导出。局部修正采用后，按图像的新状态更新该镜头的完整提示词，再核对全幅、改动局部及相关连续镜头。

## 独立封面底画

系列首回准备独立共享封面底画和标题模板，后续回目复用并替换本回文字。使用下列提示词按全局画风生成底画，打开审阅，再用排版工具合成标题。封面采用独立构图与源文件。

~~~text
为【本作品系列】绘制独立封面底画。采用绢本工笔设色叙事插画画风，【完整插入 SKILL.md 固定画法段落】。依据【全书支持且可跨回目复用的构图】组织画面，出现的人物、器物和场景保留【所绑定版本的可见特征】。主形位于【焦点与位置】，以【前中后景】形成缩略尺寸下清楚的轮廓和层次。

沿用故事图的【色彩关系、笔线、设色和材质】。为回数与原著回目在【区域、比例、背景明度】留出完整空间，文字按【阅读方向】排列。底画本身保持无字，核准后的标题另行排入透明文字层。画幅为【最终比例及裁切要求】。作为系列模板时，后续篇章延续【稳定的底画结构】。
~~~

保存完整提示词和已审阅的底画。按原模板准确排入回数与原著回目，输出并目视核对平面封面及透明文字层。后续篇章复用有效底画和模板，替换本篇文字。
