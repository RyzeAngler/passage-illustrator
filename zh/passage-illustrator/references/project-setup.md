# 新项目建立与制作规格

首次接手作品时先完成本节。已有项目读取并核对现行设定，补齐本次缺项。下文所有阶段和检查项均服从已记录的交付范围，包括配文与封面的适用条件。适用决定在第一张故事图生成前写进作品目录，后续章节复用。已有等效文件时直接更新它们。

## 明确一套画风

记录一个明确的画风名称，或一段可以直接指导绘画的完整风格描述，再展开具体的视觉要求。“山水”“田园”等词可以交代题材和气质，还需说明画法。

| 项目 | 需要确定的内容 |
| --- | --- |
| 风格名称与适用范围 | 全作的主风格，哪些人物、场景和封面采用，必要的篇章差异 |
| 媒介与笔线 | 工笔、写意、水彩、木刻等实际选择，以及轮廓、线粗、收笔、边缘的表现 |
| 设色与材质 | 主色关系、明暗幅度、层染或平涂方式、纸绢纹理和各材质的处理 |
| 形体与空间 | 人物比例、面貌表现、器物结构、景深及透视，复杂动作的可见程度 |
| 光照与气氛 | 光源与层次、昼夜处理、各镜情绪变化中仍保持的视觉特征 |
| 可复用画法段落 | 一段固定的视觉描述，逐图写入提示词；昼夜、气候和情绪另按本镜变化 |
| 规格与版式 | 画幅、尺寸、颜色空间、字体、正文及题签层级、阅读方向、封面格式 |

用户已指定画风就依其设定。新作未指定时，依据原文、对象和用途选定一套具体方案，说明并记录选择后继续制作。已有两套互斥要求时再澄清。制作一张能看清笔线、设色和形体的风格样图，打开核对后登记为画风参照；可由首张角色设定图或独立封面底画兼任。记录制作复核和用户审阅的各自状态。

## 建立作品级人物、场景与道具模型

通读本次制作范围，盘点会出现、复现或承担关键情节的实体。建立全局资产索引及各实体的有效设定，先覆盖本次范围，后续章节在同一索引增补。

| 实体 | 全局设定 | 随镜头变化的状态 |
| --- | --- | --- |
| 人物 | 稳定身份、别名、物种、脸型、体型、发式、识别特征，衣装和装备的阶段版本 | 当前衣装阶段、伤痕、动作、持有物、出入场 |
| 场景 | 出入口、朝向、固定构件、地形、重要建筑和彼此位置；需要时画平面或方位草图 | 机位、光线、可移动陈设、人物位置及现场结果 |
| 道具、武器与特殊器物 | 数量、轮廓、构件连接、材质、颜色、比例和识别特征 | 归属、开合、损坏、形变、握持与摆放状态 |

每个条目保存稳定 ID、身份或类型、阶段、版本、原文依据、创作补充、适用范围、文字描述、实际参考图路径及哈希、制作复核状态。原文未确定的外观可以设计，采用后成为本作的连续性约束。原文尚未出现的阶段标为未来或待设计。

反复出场的人物先准备可辨面貌、体型与服饰的设定图；需要换机位时补足相应视角。关键器物的构件和握持关系、反复出现的场景固定布局，也要在首用前用合适的参考图或结构草图明确。生图和看图能力可用时实际制作并核对这些参考。文字设定与视觉参考在索引中关联。资源受限或无法完成的部分明确列为待办，说明其对连续性的影响。

分镜和任务清单逐镜绑定实体 ID、阶段和版本，同时记“镜头开始时的状态—本镜变化—镜头结束时的状态”。生成时展开必要的可见特征，传入本次需要的真实参考图。前一张故事图作为现场状态补充，固定身份与设计以全局设定为准。

## 先安排配文和封面

普通章节、整回或系列图文制作默认交付一张独立封面和 N 张图文故事图。每张故事图带情节题签与对应原文配句，地点标签按需要使用。用户明确要求无字图、单幅插画或仅做分镜等特定阶段时，按其范围交付，并把选择记在制作规格。

中文古典图文若无既有版式，采用 1080×1920 的竖版 sRGB PNG，正文楷体竖排、各列从右至左，题签赭红、正文墨色、必要处加轻柔纸色衬底。按实际字量留白，其他语言和阅读场景选适用的排法。字体使用实际可读取且覆盖所需字形的文件。版式的数值与例外写入配置。图号、来源和审阅状态放在制作材料。

分镜时就选定配句并记录原文 ID，安排题签与文字区域，底图采用后由排版工具把文字实际合成到 PNG。保留无画外文字的底图。完成后核对实际成图中的字串与阅读顺序。

新系列先准备独立封面底画，用全局画法段落和封面提示词实际生成、打开审阅，再建立标题模板。每篇设置作品名、篇章标识和标题，采用其语言的阅读顺序；保留透明文字层。后续篇章沿用有效封面底画和版式。

## 开始生成前核对

- 全局风格有明确名称或完整描述，画法段落和已核对参照可读取。
- 本次出场的人物、场景和道具有设定、阶段与有效版本；关键参考已准备，逐镜绑定已完成。
- 交付带配文成图时，逐图原文配句、题签、版式和留白已安排；明确的无字或特定阶段请求决定本次适用工作。
- 本次范围包含封面时，底画及模板已有有效来源或已列入实际制作，标题和输出路径明确。

只有故事底图完成时，继续做已约定的配文与封面。技术或资源阻塞时明确列出缺项和当前完成阶段。
