# 资产与连续性

先检索全局资产索引，再补充确有缺项的身份、阶段、场景或物件。同一角色的别名共用身份；阶段改变衣装、装备或状态，不随意重造面貌。

| 类型 | 需要固定的内容 |
| --- | --- |
| 画风 | 媒介、线条、设色、肌理和材质表现 |
| 人物 | 面部结构、体型、辨认特征，以及当前衣装和装备 |
| 群演 | 类型、年龄、体态差异与组合，避免复制主角面貌 |
| 器物 | 数量、轮廓、组成、连接、材质、比例和使用状态 |
| 场景 | 地形、出入口、固定构件、相对位置及可识别空间关系 |

具体设定和原文依据保存在对应资产中。

采用资产前打开实际图像核对关键特征。候选经过制作复核后可在已验证范围内使用，仍保留其用户审阅状态；未经验证或仍有误的特征不得向后传播。已有确认只适用于对应版本和范围。

连续性同时对照全局有效设定与相关前图。固定设定防止逐张漂移，前图用于核对现场状态；不能只因引用了同一文件或名称就判定输出一致。换机位时保持物件身份、人物自身左右和空间关系，允许画面位置与投影随视点变化。

资产内容改变后，核对当前制作清单中所有受影响镜头；前图改变后，重新判断后续镜头的相关连续性。跨篇章仍有引用的有效版本保留，不自动替换或删除。
