# 配文、封面、导出与交付

章节或系列按[新项目建立与制作规格](project-setup.md)确定默认交付，生图前落定画风与版式。交付前逐项打开带配文的实际 PNG、独立封面 PNG 和透明封面文字层核对。明确的无字图、单幅插画等范围按记录执行。

## 配文、画内文字与排版

画内题字、铭文或标识的字串、字形及书写习惯服从原文和作品设定。逐字核对，检查是否位于正确载体，透视、表面纹理、光照与物体应当一致。原文要求可读的文字须在最终尺寸下可辨。

画外配文优先选能说明当前场景的原句，可以来自诗词、正文或对话。先保证意思完整，再决定长短；非连续摘句在配置中标明省略。题签、概括、转写和原引分别记录。地点已经由可读的画内文字交代时，可关闭重复地点标注。图像中只呈现作品需要的文字；段落编号、出处、审阅状态与生成说明保存在制作材料。

先确定作品的全局版式，再写本次必要差异。以下参数以成品像素和实际可读取的字体文件为依据。

| 对象 | 作品需确定的参数 |
| --- | --- |
| 画布与裁切 | 宽高、阅读方向、画幅适配方式、逐图裁切重心与坐标基准 |
| 正文 | 字体文件与字库索引、字号、字步、行步或列步、文字颜色 |
| 题签与地点 | 各自位置、字号、颜色和显示条件 |
| 衬底与边界 | 颜色、不透明度、文字联合边界外扩与柔边宽度；背景纹理可辨 |
| 画面避让 | 给全组文字及柔边留出位置，避开脸、手、主要动作、关键物件和画内文字 |

每图配置关联图号、标题、源图路径和哈希、实际原文段落、文字内容及位置。换底图后更新哈希，重新检查构图、裁切和留白。以正式底图一次适配成品尺寸；排字或裁切不得遮住原有形体问题。制作完成要查看实际成图，技术工具可验证引文、边界和像素，画面遮挡及字形协调仍需目视检查。

## 封面与导出

新章节或系列在本次制作中建立独立封面底画和全局标题模板。先用封面提示词和统一画法段落实际生成底画，打开审阅，登记来源和哈希。已有系列复用有效底画和模板。模板保存背景、画布、字体与标题位置，每次替换本篇标识和标题。长标题核对字形边界、阅读顺序，必要时调整对应位置和字号。保留平面封面、透明文字层、背景和实际使用的字体信息与哈希，便于再次套版。

使用作品已有工具或 Skill 附带的排版导出工具。后者按配置生成故事 PNG、HTML 审阅页、成图清单和故事图 ZIP，配置了封面时另出封面与透明文字层。缩略总览 JPG 按需生成。命令与字段见[导出配置](export-format.md)。

| 变更 | 更新与复核范围 |
| --- | --- |
| 配文、题签、地点或排字样式 | 修改排字配置，从同一正式底图重新导出成图和交付材料，复核文字与遮挡 |
| 单图内容 | 更新完整提示词、底图、制作绑定、哈希和目视结论，再排字、生成清单和打包 |
| 共用身份、阶段、器物或场景 | 更新有效设定、相关任务绑定及受影响的逐图提示词和验收 |
| 章节标识或标题 | 更新封面文字配置，导出封面及文字层，复核标题排列和边界 |

## 成图目视复核

先连续阅读整组，再逐张看全幅和关键局部。确认情节顺序和转折、人物、道具和地点连续；确认底图中的关键关系在成图中仍可见。逐字核对画内文字与载体；画外文字检查字形、字体、阅读方向、断行断列、衬底和目标阅读尺寸下的可读性。封面复核底画、篇章标识、标题和阅读顺序。把观察写入对应成图的当前目视记录。

## 技术检查与交付

1. 图号连续、文件名唯一、数量与配置一致，封面单独计数。
2. 成图与封面的尺寸、格式、色彩空间符合本作规格。使用附带工具时，输出带 sRGB ICC 的 RGB PNG；封面文字层为同尺寸 RGBA。
3. 底图、配置、清单与磁盘文件哈希相符；正式底图保留原始像素，材料可重新排字和导出。
4. 配文可以定位到原文，转写和省略有依据，题签与引文区分。
5. 任务、资产、提示词、排字、封面及审阅入口所需文件可读取，链接指向有效材料。
6. 审阅页使用当前成图版本；缩略总览仅在本次生成时提供入口。
7. 故事图包按阅读顺序仅收录约定的插画，核对 ZIP 文件次序、CRC 和包内文件 SHA-256。
8. 技术报告只记录实际执行的项目。制作目视审阅对应当前底图、成图和参照版本；用户审阅如实标明。

按用户要求交付图像、独立封面和故事图包。系列提供 README 或其他项目入口及可打开的审阅页，只保留当前状态与有效链接。
